## Descripcion

Taller práctico sobre estructuras de datos lineales en Java. El proyecto
implementa 15 ejercicios que cubren arreglos unidimensionales, arreglos
bidimensionales (matrices) y la clase ArrayList.

Los datos de relleno se generan de forma aleatoria y todos los ejercicios
se ejecutan desde consola mediante un menú interactivo. El código sigue
los principios de Clean Code y el paradigma de programación orientada a
objetos, separando en cada ejercicio la generación de datos, el
procesamiento y la impresión de resultados.

## Estructura del proyecto
src/
├── app/ Clase Main con el menú de ejecución
├── arreglos/ Ejercicios 1 a 5 — arreglos unidimensionales
├── arraylist/ Ejercicios 6 a 10 — ArrayList
├── matrices/ Ejercicios 11 a 15 — arreglos bidimensionales
└── util/ Clases de apoyo reutilizables


## Requisitos

- JDK 17 25 o superior
- Visual Studio Code con la extensión "Extension Pack for Java"
- El archivo data/PartidoLiga.txt debe estar presente en la raíz del
  proyecto (ya incluido en el repositorio) para que el Ejercicio 10 funcione

## Instrucciones de ejecución

1. Abrir la carpeta del proyecto en VS Code (File y Open Folder).
2. Abrir el archivo `src/app/Main.java`.
3. Hacer clic en el botón **Run** que aparece sobre `public static void main`.
4. Escribir en la terminal el número del ejercicio que se desea ejecutar.
5. Escribir 0 para salir.
